# Домашнее задание к работе 8

### Задание 3

## Условие задачи

1. **Организовать** ввод степени `n` пользователем.
2. **Вывести** в столбик значения `2^i` от `0` до `n` с выравниванием по правому краю.
3. **Выполнить** вычисления последовательно для трех типов данных:
   * `int`
   * `unsigned int`
   * `long long`
4. **Определить** для каждого типа последнюю корректную степень, значение результата и поведение при переполнении.

## Алгоритм работы программы и блок-схема

### Алгоритм

1. **Начало.**
2. Установить кодировку для вывода русского текста.
3. **Последовательно** выполнить три эксперимента с разными типами данных:
   * **Эксперимент 1 (тип `int`):** запустить цикл от 0 до 31, вычислить `2^i`, вывести результат. Если число стало отрицательным — вывести сообщение о переполнении и прервать цикл.
   * **Эксперимент 2 (тип `unsigned int`):** запустить цикл от 0 до 32. Если `i == 32` — вывести сообщение о переполнении и прервать цикл. Иначе вычислить `2^i` и вывести результат.
   * **Эксперимент 3 (тип `long long`):** запустить цикл от 0 до 63, вычислить `2^i`, вывести результат. Если число стало отрицательным — вывести сообщение о переполнении и прервать цикл.
4. **Конец.**

### Ответы на контрольные вопросы

1. **Как изменился диапазон положительных значений при переходе от `int` к `unsigned int`?**
   Диапазон положительных значений увеличился ровно в 2 раза. У `int` максимальное положительное число — \(2^{31}-1\), а у `unsigned int` — \(2^{32}-1\). Это произошло потому, что у `unsigned int` старший (31-й) бит больше не используется для хранения знака, а полностью отдан под само число.

2. **Что изменилось при переходе от `unsigned int` к `long long`?**
   Размер типа данных увеличился с 32 бит (4 байта) до 64 бит (8 байт). За счет этого максимальное значение, которое можно сохранить в переменной, колоссально возросло (примерно в 4 миллиарда раз). Однако `long long` является знаковым типом, поэтому на 63-й степени он тоже уходит в минус.

3. **Почему увеличение размера типа позволяет вычислить больше степеней двойки?**
   Степень двойки в двоичном представлении — это единица и несколько нулей (например, \(2^3 = 1000_2\)). Чтобы сохранить такое число, компьютеру нужно столько бит памяти, сколько нулей в этом числе. Чем больше бит выделено под переменную (32 бита у `int`, 64 бита у `long long`), тем дальше можно сдвинуть единицу влево, прежде чем она "вылетит" за пределы памяти.

4. **Что происходит с результатом после выхода за диапазон типа?**
   Происходит **целочисленное переполнение**. В языке C это работает как "срезание" лишних битов:
   * Если сдвинуть единицу в знаковом числе (`int`, `long long`) на позицию знакового бита, число становится **отрицательным**.
   * Если продолжать сдвигать дальше, число может стать нулем (все биты сдвинулись и потерялись) или начать зацикливаться (как у `unsigned int`, где после 0 снова появляется 1, затем 2 и т.д.). Программа при этом не выдает ошибку, а просто продолжает работать с искаженными данными.
