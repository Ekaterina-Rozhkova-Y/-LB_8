## Вариант 22. Произведение (1 + sin(x))

### Постановка задачи
Вычислить с использованием цикла `for` значение произведения:
`(1 + sin(0.1)) * (1 + sin(0.2)) * ... * (1 + sin(10))`


### Алгоритм

1. Начало.
2. Запросить у пользователя начальное значение `a` (например, 0.1).
3. Запросить у пользователя конечное значение `b` (например, 10.0).
4. Запросить у пользователя шаг `h` (например, 0.1).
5. Инициализировать переменную для произведения: `product = 1.0`.
6. Вычислить количество шагов цикла: `steps = (b - a) / h + 1`.
7. Запустить цикл `for` с параметром `i` от 0 до `steps - 1`:
    * Вычислить текущее значение аргумента: `x = a + i * h`.
    * Умножить текущее произведение на член ряда: `product = product * (1.0 + sin(x))`.
8. Вывести на экран итоговое значение `product`.
9. Конец.
